  • Virtual Memory & Processes: Optimized a 2-level page table with a TLB Fast Refill handler in assembly, and implemented a TLB Mod exception-based Copy-on-Write (CoW) fork() to reduce memory overhead.
  • Microkernel Architecture: Built a user-space (Lab5) FS server process and implemented shared-page Pipe IPC (Lab6) to enable communication with components outside the kernel.
🚨 Key Troubleshooting: Resolved IPC Race Condition Without Locks

During Pipe IPC implementation, a concurrency bug arose where pipe_is_closed() = pageref(fd) == pageref(pipe) would falsely report an open pipe as closed depending on scheduling timing. The root cause was a transient state where fd_ref ≥ pipe_ref held momentarily. Fixed by reordering operations: close() unmaps FD first → Pipe second; dup() maps Pipe first → FD second — ensuring the invariant pageref(fd) ≤ pageref(pipe) always holds, achieving stable concurrency without any locks.

During error recovery for missing semicolons, the token pointer advanced too far, causing cascading false errors on subsequent valid syntax. Fixed by anchoring error reporting to the last valid token of the preceding semantic unit (getPreviousToken()) while continuing to parse — completing a fault-tolerant parser.
