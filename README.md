# Portfolio

조현준 포트폴리오 정적 사이트입니다.

## Structure

- `index.html` - 메인 포트폴리오 페이지
- `assets/images/` - 프로필 이미지 등 공용 이미지
- `assets/previews/` - 미리보기 이미지
- `documents/certificates/` - 어학 성적표 등 증빙 자료
- `documents/resumes/` - 이력서 PDF/ZIP
- `documents/portfolio/` - 포트폴리오 문서 및 출력본
- `pages/` - 제출처별 보조 HTML 페이지
- `runtime/browser-profiles/` - 로컬 브라우저 실행 산출물
