왜 쏘카에 지원하는가

쏘카 IT 운영은 단순히 문의를 처리하는 역할이 아니라, 구성원들이 기술적 불편 없이 일할 수 있도록 업무 환경 자체를 안정적으로 설계하고 유지하는 역할이라고 이해했습니다. 저는 개발 프로젝트에서 장애를 만났을 때 코드만 보지 않고 로그, 컨테이너 상태, 서버 자원, 문서화된 절차까지 함께 확인하며 원인을 좁혀 왔습니다.

특히 이 포지션의 Helpdesk, 계정 라이프사이클, 보안 솔루션 문의 대응, SaaS/라이선스 관리, IT 비용 정리는 모두 “정확한 기록과 빠른 소통”이 핵심이라고 생각합니다. 저는 RFC와 README로 운영 절차를 남기고, 한·중·영 환경에서 팀 컨텍스트를 맞춰 본 경험을 바탕으로 쏘카 구성원의 업무 흐름을 끊기지 않게 돕고 싶습니다.

개발자로서의 깊이보다 운영자로서의 태도가 더 중요하다는 점도 알고 있습니다. 모르는 영역은 과장하지 않고 빠르게 확인하며, 반복 문의는 문서와 프로세스로 줄이는 방식으로 쏘카 IT 인프라 운영 효율에 기여하겠습니다.

운영 안정성 API 500 장애를 앱 로그 → 컨테이너 상태 → OS 커널 로그 순서로 추적한 경험
문서화 README, RFC, 배포 체크리스트 기반으로 팀 합의와 운영 절차를 명문화
계정·권한 이해 JWT, Spring Security, 사용자 연결 API 설계 경험을 Keycloak/VPN/VDI 계정 관리 학습으로 확장 가능
커뮤니케이션 한·중·영 업무 소통 가능, 다양한 부서 요청을 정확히 듣고 정리하는 데 강점

공고 업무와 나의 연결점

IT Helpdesk
문제 재현, 로그 확인, 원인 분리, 사용자에게 이해 가능한 언어로 안내하는 트러블슈팅 습관
네트워크·보안
직접 NAC/RADIUS 운영 경험은 없지만, 인증·권한·연결 흐름을 구조적으로 이해하고 빠르게 문서 기반으로 습득 가능
계정·권한
Spring Security/JWT, 사용자 연결 API 경험을 바탕으로 계정 생성·회수·권한 변경의 리스크를 신중하게 관리
비용·라이선스
클라우드 배포와 외부 서비스 구성 경험을 바탕으로 비용 항목을 구조화하고 갱신·해지 내역을 꼼꼼히 기록

직무 적합 근거

IT 운영 지원에 맞는 태도

  • 문의의 표면 증상보다 실제 원인을 찾기 위해 재현 조건과 로그를 먼저 정리합니다.
  • 반복되는 문제는 개인 응대에서 끝내지 않고 문서와 체크리스트로 전환합니다.
  • 비개발 구성원에게도 이해되는 언어로 원인, 조치, 재발 방지 방법을 설명합니다.

쏘카 업무에서 바로 쓰일 강점

  • AWS EC2, Docker Compose 배포 경험으로 클라우드/서버 운영 용어와 흐름에 익숙합니다.
  • 권한 만료, 인증 실패, 외부 API 연결 실패 같은 운영 이슈를 추적한 경험이 있습니다.
  • RFC 문서화와 다국어 주석으로 팀 합의와 운영 맥락을 남겨 본 경험이 있습니다.

대표 경험

CareLink · AWS / Docker / Logs

EC2 로그 기반 장애 원인 추적

ECG 분석 API 500 오류를 백엔드 로그, AI 컨테이너 상태, Ubuntu 커널 로그 순서로 좁혀 Connection refused와 모델 파일 경로 문제를 분리했습니다. 운영 이슈를 코드 밖 인프라까지 확장해 확인한 경험입니다.

Academic Platform · Docs / RFC

운영 절차와 API 규약 문서화

Spring Boot, PostgreSQL, Elasticsearch, Redis, MinIO를 통합하면서 API 응답 규약과 팀 합의 내용을 RFC/README로 기록했습니다. 반복 커뮤니케이션 비용을 줄이는 문서화 방식을 익혔습니다.

Security Flow · JWT / Accounts

계정·권한 흐름 이해

JWT 만료 자동 로그아웃, 사용자 연결 API, 인증 실패 흐름을 구현했습니다. Keycloak, VPN, VDI, GCP 계정 관리 업무에서도 권한 변경의 영향 범위를 신중하게 확인하는 기반이 됩니다.

Communication · KR / CN / EN

다부서 협업에 맞는 소통

중국 소프트웨어공학 환경에서 한·중·영으로 학습하고 협업했습니다. 다양한 부서의 문의를 받아 정확히 요약하고, 필요한 경우 가이드 문서로 남기는 업무에 강점이 있습니다.

쏘카에서의 기여 방향

입사 초기에는 문의 응대와 계정 처리의 정확도를 최우선으로 두고, 자주 반복되는 요청을 유형화하겠습니다. 이후에는 Wi-Fi/VPN/VDI/NAC 관련 사용자 가이드와 체크리스트를 정리해 Helpdesk 응답 속도와 일관성을 높이고 싶습니다.

또한 SaaS, 클라우드, 외부 서비스 비용 항목을 한눈에 파악할 수 있도록 구독 현황과 갱신 일정을 정리하며, 쏘카 구성원들이 업무에 몰입할 수 있는 안정적인 IT 환경을 만드는 실무형 운영자가 되겠습니다.
