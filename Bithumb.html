01

SysY 언어 컴파일러 프론트엔드 & P-Code VM

2024.10 – 2025.01 · 1인 개발
C++17 · Lexer / Parser / Symbol Table / P-Code VM · Fault-Tolerant Parser · CMake

SysY 언어의 어휘 분석기, 재귀 하향 파서, 심볼 테이블, P-Code 생성기, VM 인터프리터까지 컴파일러 전체 파이프라인을 C++17로 구현했습니다. 복잡한 소스코드 구조를 읽고, 상태 전이와 예외 복구 흐름을 분석하는 역량을 보여주는 프로젝트입니다.

구현
  • Lexer, Parser, SymbolTable, ErrorHandler, Interpreter 모듈로 구조를 분리하고 CMake 기반 빌드를 구성해 변경 영향 범위를 줄였습니다.
  • 재귀 하향 Parser에서 선행 탐색, 모호성 판별, 연산자 우선순위 기반 계층적 식 파싱을 구현했습니다.
  • 산술·논리 연산, 분기, 반복, 함수 호출/반환, 배열 인덱싱을 처리하는 자체 P-Code 명령어 셋과 스택 머신 VM을 구현했습니다.
문제

세미콜론 누락 같은 작은 문법 오류가 발생했을 때 토큰 포인터가 과도하게 이동해 정상 구문까지 연쇄적으로 오류로 판정하는 문제가 있었습니다.

해결

에러를 파싱 중단 사유가 아니라 문맥 복귀 신호로 재설계하고, 직전 의미 단위 기준 위치인 mLastNonT를 기록해 연쇄 오진을 줄였습니다.

연결

블록체인 노드나 스마트 컨트랙트 코드 분석에서도 복잡한 상태 전이, 예외 조건, 실행 흐름을 읽어야 합니다. 이 프로젝트는 소스코드 레벨 검증의 기반 역량을 직접 보여줍니다.

02

MIPS 마이크로커널 운영체제

2024.03 – 2024.07 · 1인 개발
C · MIPS Assembly · Virtual Memory · CoW fork · IPC · User-space FS · Lock-free race condition 해결

GXemul MIPS 환경에서 커널 부팅, 메모리 관리, 프로세스, 시스템콜, IPC, 파일시스템까지 OS 핵심 구성요소를 단계적으로 구현했습니다. 블록체인 노드 분석에 필요한 프로세스, 메모리, 파일시스템, 동시성 이해의 기반이 된 프로젝트입니다.

구현
  • 2단계 페이지 테이블과 TLB Fast Refill 핸들러를 어셈블리로 구현하고, Copy-on-Write 기반 fork()를 구현했습니다.
  • 독립된 사용자 공간 FS 서버 프로세스와 IPC로 통신하는 마이크로커널 파일시스템 구조를 구현했습니다.
  • 공유 페이지 기반 Pipe IPC, 파일 디스크립터 복제(dup), 참조 카운트(pageref) 관리 로직을 설계했습니다.
문제

Pipe IPC 구현 중 매핑 순서에 따라 참조 수 판정이 흔들려 열린 파이프를 닫힌 것으로 오인하는 동시성 문제가 발생했습니다.

해결

pageref(fd) ≤ pageref(pipe) 조건이 어떤 순간에도 깨지지 않도록 unmap/map 순서를 조정했습니다. 외부 락 없이 실행 순서만으로 IPC 안정성을 확보했습니다.

연결

거래소의 월렛·입출금·노드 연동은 시스템 경계와 동시성 조건을 정확히 이해해야 합니다. 이 프로젝트는 낮은 수준의 상태 불변식을 추적하고 검증한 경험입니다.

CareLink — Docker/AWS 기반 PoC 운영 검증

2025.10 – 2026.03 · 1인 개발 / 졸업논문
React Native · Spring Boot · FastAPI · PyTorch · Docker · AWS EC2 · TPS 66 · AUC 92.52%

모바일, 백엔드, AI 추론 서버를 3-Tier로 분리하고 Docker/AWS EC2 환경에서 동작 가능성을 검증했습니다. 새로운 기술을 실제 시스템에 연결하기 전 성능, 자원, 배포 리스크를 작은 PoC로 확인하는 방식과 연결됩니다.

구현
  • Spring Boot 백엔드와 FastAPI AI 추론 서버를 분리하고, Docker 컨테이너 기반 실행 환경을 구성했습니다.
  • PTB-XL 데이터셋 기반 ECG 모델을 구축해 Macro AUC 92.52%를 달성하고, AWS 환경에서 TPS 66을 측정했습니다.
  • JWT 인증, Cache-First 전략, 서버 사이드 추론 구조를 적용해 클라이언트와 백엔드 간 데이터 흐름을 검증했습니다.
리스크

AI 컨테이너와 백엔드를 동시에 구동하면 1GB RAM EC2에서 OOM이 반복됐습니다. 단순 코드 수정만으로 해결하기 어려운 운영 리스크였습니다.

해결

로컬/CI에서 이미지를 빌드하고 서버는 Pull-only로 운영하도록 전환했습니다. Docker mem_limit과 profile로 컨테이너별 자원을 격리했습니다.

연결

블록체인 기술을 거래소 시스템에 도입할 때도 PoC로 연동 조건과 운영 리스크를 먼저 확인해야 합니다. 이 프로젝트는 기술 검증과 적용 전략 수립 경험으로 연결됩니다.

구현

  • Spring Boot 공통 응답 래핑과 전역 예외 처리 구조를 구현해 프론트엔드 파싱 오류를 제거했습니다.
